## 流程

**1. 先看问过没有**
```bash
PYTHONPATH=. /Users/xiaolibird/miniconda3/envs/env002_reader/bin/python3.12 scripts/ask_notes.py --list
cat output/scholar_notes/topics/qa/INDEX.md
```
**2. 先 dry-run 看召回够不够**（不调 LLM、不落盘）。默认只列前 10 条，想确认某篇有没有被召回就加 `--show 40`；开头一行「参数：…」回显实际生效的角色/阈值，先看一眼有没有沿用了不想要的限制。
```bash
PYTHONPATH=. /Users/xiaolibird/miniconda3/envs/env002_reader/bin/python3.12 scripts/ask_notes.py "<问题>" -q "<英文术语>" -q "<换个说法>" --dry-run
```
**3. 真问并归档**：去掉 `--dry-run`。

- `-q/--query` 是**额外检索词**，不改变问题本身；每个词各检索一次后合并（不拼成一句，拼接会把几个概念平均成一个语义中点）。关键术语中英文两种写法都给——中文查询能命中英文原文，但概念换述的召回率实测只有约 30%。
- `--role {citable,refutable,method}` 可重复，只用该角色的证据；缺省三者都要。
- `--max-evidence`（默认 28）、`--min-sim`（默认 0.55，句级口径，勿照抄 paper 级阈值）、`--per-paper-cap`（默认 3，窄而深，有意比概念页的 4 小）。
- **v3 新参数**（2026-10-04，转述失真可见/可拦）：
  - `--audit {theory,all,off}`：蕴含审计，一次额外 LLM 调用，逐条判「转述是否忠实于所引原句」。`theory`（默认）只审理论类论断，`all` 审全部依据与注意事项，`off` 关闭。审计失败不阻断归档，页面顶部明说「本页未经蕴含审计」，frontmatter `audit_status: failed`。
  - `--audit-model <模型>`：审计用的模型，缺省与合成相同。
  - `--strict`：审计判「不忠实」的论断直接丢弃（默认只标 ❌ 不删），被丢的原文与理由列在页尾「审计记录」。
  - `--theory` / `--no-theory`：理论模式开关。缺省自动触发（问题或 `-q` 命中 定理/命题/保证/下界/可识别/不可能 等关键词）；正常召回后，扫候选池里出现过的**全部论文**（不按论文级排名截：对口论文的定理句分数偏低，论文排名可能很靠后），仅命中「定理类名词 + 编号」（Theorem 2.3 / Prop. 2.6 / 定理1 / 命题 2.8 / 假设 1）且句分 ≥ 阈值的句子（只含「假设」「保证」等宽泛词的批评句、实验句不补捞）按自身得分全局降序补捞，每篇最多 3 句、总数最多 12 条（`--theory-max N` 可调）。`--no-theory` 强制关闭。
  - `--theory-min-sim <x>`：补捞用的放宽阈值，默认 0.45（公式密集句与自然语言问题的余弦偏低，实测 0.54）。补捞句不受 `--per-paper-cap`/`--max-evidence` 截断（额外配额，最多 `--theory-max` 条，证据总数可能略超 `--max-evidence`）。
  - 终端会多打两行：`📐 理论模式：从 K 篇补捞 N 条定理/命题句`（K = 实际贡献了补捞句的论文数）；用了 `--role` 时还有 `⚠️ 角色过滤（xxx）挡掉 N 条高分证据，其中 M 条含数字`（统计口径是每个 query 的 top-80 内，是下界）。看到 M>0 且问的是数字/事实，重问时加 `--role all`。frontmatter 记 `theory_mode`/`theory_backfilled`/`role_filtered_out`/`role_filtered_numeric`。
- **证据不足拒答**（2026-10-13）：召回后按该问题自己的全库相似度分布判一次，独立来源（按 keeper 去重、撤稿不计）< 2 就**不调 LLM**，归档一页「库内证据不足」存根（退出码 0，终端打 `📭` 与判定数字：动态阈值、来源数、最高分）。存根页是有效答案——问过了、库里不够，下次查重会命中。认为是误拒就加 `--force-synthesize`（照常合成，页面标「证据不足时被强制生成」）。已有的好页若这次判不足，不会被存根覆盖（倒退保护，退出码 2，多半是向量库问题）。
- `--slug <名>` 指定文件名（自动加 `qa-` 前缀）；该 slug 已属于另一个问题时直接报错退 2，不会静默覆盖别人的问答。

**重问**（检索参数随每页归档进 frontmatter，重问时原样复现）：
```bash
… ask_notes.py --reask <slug>        # 可重复；-q / --max-evidence 等给了就整体覆盖存档值，不是追加
… ask_notes.py --reask-all            # 只打印「计划重问 N 页」
… ask_notes.py --reask-all --yes      # 真的全部重问
… ask_notes.py --verify               # 自检归档页的引用是否仍可追溯
```

## 读答案时要知道的

- 每条论断带 `[@citekey]`，页底证据表给 `note_file:note_line`。**要把具体数字写进稿子，先点开原句核对**——防线保证 citekey 与原句真实存在，不保证转述没有失真。
- **v3 页面徽标怎么读**：
  - `⚠️ 数字未在所引证据中找到：X、Y`（论断下一行）：这条论断里的数字在它所引的证据句里找不到，可能是转述失真，也可能是自行换算。回原句核对。边界：只判「转述 vs 所引证据」，不判「证据 vs 原文」——精读句本身抄错的数字（如 PaO2）会判已接地，那类错要回论文截图核对。
  - `📌 原句（理论类论断，请对比方向与限定条件）`：理论类论断（涉及定理/保证/界/可识别/不可能）下方贴出所引证据的**全文原句**。读法：逐条对比论断与原句的方向（可证 vs 不可能）、限定条件（MCAR 且 Y⊥M|X）、水平（1−α vs 1−2α）、证据类型（实验观察 vs 理论保证）。实证类论断不贴。
  - `❌ 审计` / `❔ 审计`：蕴含审计的结论。❌ = 判「不忠实」（论断前也有 ❌，页首还有总数提示，answer 可能受其影响）；❔ = 「无法判断」。理由一句话指出哪个词/方向/条件不符。审计本身是 LLM，**不是终审**：❌ 要回原句确认，没标 ❌ 也不等于忠实，尤其是理论类仍应对比 📌 原句。
  - 证据表里的 `（理论补捞）`：这条句子不是正常召回命中的，而是理论模式按篇补捞进来的（阈值放宽到 0.45）。相关度比普通证据低，可能只是同篇里带定理关键词的邻句，使用前看原句是否真回答问题。
- **页首「本页覆盖范围」**：库是按画像筛选的方法学库，证据表只来自有句级精读的那部分（约 40%）；写了本页证据有几篇独立来源、几篇只读到摘要，以及**库里没有 ≠ 文献里没有**（要确认领域里有没有人做过，用 `scholar-search`）。论断行末的 `［单一来源］` 表示只挂了一个独立来源——强度轴，与 ❌/❔ 的忠实度轴是两回事。frontmatter 的 `synth_model` / `synth_model_verified` 记录合成用的模型（取不到应答者时 verified 为 false）。
- 「⚠️ 用之前要知道的」是限制条件。「**本次召回没覆盖到的**」**不等于「库里没有」**，只是这一次那几十条证据没能回答的部分；脚本会拿每条空白回查向量库与概念页，命中标「⚠️ 但库里可能有」。没标记也别当结论，先查 `topics/INDEX.md` 与 `notes_search.py` 再决定要不要补文献。
- ⚠️ **理论/定理类问题，归档页的综合不可信，要回原文核对**（2026-10-03 同一问题三次实测，zaffran2024 的结论是：无分布假设下按缺失模式的条件覆盖不可达，仅 MCAR 且 Y⊥M|X 可证、水平 1−2α）：
  1. 默认参数：召回只抓到一条**实验句**，答案写成「CP-MDA 对各种缺失模式维持不低于名义水平 1−α 的覆盖」，与原文理论不符。
  2. 加 `-q` 定理关键词 + `--role citable`：定理句仍被默认 `--min-sim 0.55` 切掉（公式密集的句子与自然语言问题相似度偏低，实测 0.54），答案反而变成「证据不足」。
  3. 再加 `--min-sim 0.45 --max-evidence 36`：Proposition 2.6 召回到了，但综合时**把「硬度/不可能」结果转述成了正面结果**（写成「CP-MDA 类理论结果被限定证明于 P_MAR 或 P_MCAR 分布族内」，原文是：即使只限 MAR 或只限 MCAR，同一不可能下界依然成立）。
  防线只保证 citekey 与原句真实存在，管不了语义方向。**凡涉及保证/界/定理/可识别性/「不可能」的论断，以论文精读里的原句为准，不要引问答页的转述。** 召回侧要点：理论类问题给 `-q` 写定理关键词，并把 `--min-sim` 降到 0.45 左右。
- ⚠️ **归档问答不在向量库里**（概念页也不在，同一笔已知欠账），`notes_search.py` 搜不到。找旧问答用 `--list`、读 `topics/qa/INDEX.md`，或在 Obsidian 的 `02-主题/问答/` 里全文搜。
- ⚠️ Obsidian 那份要等下一次索引重建才出现（vault 同步只被 `literature_index.json` 触发）。
- 同一问题再问是**原地更新**那一页：空白、标点、全半角、零宽字符都归一化，少打一个问号不会另开一页；问之前自动做语义查重，给出 slug 与可直接粘的更新命令。
- 改过文献的 citekey（如撤稿后改键、重新入库换键）后，旧问答页里的 `[@旧键]` 不会自动跟着改：要么 `--reask <slug>`，要么先扫一遍再说。

## 反面示例（真实案例，2026-10-03，别学）：定理类论断被综合歪了

**问题**：「信息性缺失下，共形预测的覆盖保证能做到什么程度？」（对口论文 zaffran2024，Predictive UQ with Missing Covariates）

**论文精读里的原句（以此为准）**
- Proposition 2.6（p9-10）：把方法限定为只对 P_MAR 或只对 P_MCAR 做 MCV，**同一不可能下界依然成立**。→ 这是**硬度结果**：只限 MAR 或只限 MCAR 也救不了。
- Theorem 4.3（p21-22）：仅在 **MCAR 且 Y⊥M|X** 下 CP-MDA-Nested* 可证 MCV，**水平是 1−2α，不是 1−α**。
- Table 2（p6）：一般分布下 MCAR/MAR/MNAR 三列均为硬度；MAR 且 Y⊥M|X 为问号（理论未定）。

**归档页的三种写法（全都错）**

| 轮次 | 归档页写的 | 错在哪 |
|---|---|---|
| 默认参数 | 「CP-MDA 系列可在各缺失模式大小上维持不低于名义水平 1−α 的覆盖（与 Theorem 4.3 一致）」 | 把**实验里观察到的覆盖**说成理论保证；Theorem 4.3 的水平是 1−2α 且只在 MCAR 且 Y⊥M\|X 下成立。召回只抓到一条实验句（Fig. 3a），定理句没进来 |
| 加 `-q` 定理词 + `--role citable` | 「本次证据不足以给出针对 MNAR 的覆盖保证」 | 定理句被默认 `--min-sim 0.55` 切掉（实测 0.54）；论文其实明确给了结论（MNAR 下条件覆盖不可达，边际覆盖仍成立），答案却说没有 |
| 再降 `--min-sim 0.45` | 「CP-MDA 类理论结果本身被限定分别证明于 P_MAR 或 P_MCAR 分布族内（同一下界 Δ 依然成立）」 | **符号整个反了**：Prop 2.6 是「只限 MAR 或 MCAR 也不可能」，被转述成「在 MAR 或 MCAR 范围内可证」 |

**为什么防线没拦住**：每个 `[@citekey, p.X]` 都真实存在、页码也对，`--verify` 全绿（244 处引用可追溯）。防线只管「引文存在」，不管「转述的方向对不对」。

**怎么做才对**
1. 凡论断里带「保证 / 界 / 定理 / 可识别 / 不可能 / 硬度 / 水平 1−α」，**不要引问答页的转述**，回论文精读（`scholar-notes` 查该篇 highlights）取原句，引原句。
2. 这类问题的召回：`-q` 写定理关键词与符号，`--min-sim` 降到 0.45 左右，`--max-evidence` 适当加大；召回到了也只是「句子对了」，综合仍要核。
3. 汇报时对这类论断必须明说「**转述未回原文核对**」，不要把问答页的结论当成论文的结论转给用户。
4. 看到「证据不足 / 库里没有」也别信：这个案例里论文明明给了明确结论，只是没召回。先 `notes_search.py` 按论文名与定理关键词直接查那一篇。

## 正面示例（真实案例，2026-10-03）：实证数字类问题 + 逐条回截图核对

**问题**：「不同医院之间，同一项检验或测量的缺失率差异有多大？有没有实证数字？」——答案是**具体数字**，不涉及定理，这类问题问答页综合得比较稳。

**一路踩坑才问对（先看失败再看成功）**

| 轮次 | 参数 | 结果 | 原因 |
|---|---|---|---|
| 1 | `-q` 泛泛的英文词 + `--role citable --min-sim 0.5` | 引用率 25%、没用上最对口的 MDLA | `-q` 没点到具体对象 |
| 2 | 换成具体 `-q`（「两个数据库中同一变量的缺失率 MIMIC 与 eICU 对比」等） | 仍然 0 条 MDLA | **`--reask` 沿用了存档里的 `--role citable`**；那条「PaCO2 46.42% vs 69.01%」在精读里被标成**可反驳观点**（批评论文只把它当分布偏移），被 role 过滤挡掉 |
| 3 | 同样的 `-q`，**清掉角色限制** `--role all` | MDLA 4 条进来，引用率 43% | ✓ |

**要点**
1. **`--role citable` 会把「标成可反驳观点但里面有硬数字」的句子一并挡掉。** 问数字、问事实时不要限定角色；只有要专门找「可引证据」或「可反驳点」时才限。
2. **`--reask` 的 `-q`/`--role` 等给了就整体覆盖存档值，不给就沿用存档值。** 想清掉某次留下的 `--role` 限制，用 `--role all`（2026-10-03 新增；之前没有清空写法，只能把三个角色都显式给全）。开头那行「参数：角色=… | min-sim=…」会回显这一次**实际生效**的值，沿用了什么一眼能看到。
3. `-q` 要点到**具体对象和度量**（哪两个库、什么变量、什么量），不要只给领域词。同一句话 `notes_search` 里排第 3、`ask_notes` 里 0 条，多半是 role、`--min-sim` 或 `--per-paper-cap` 在作怪，不是向量坏了。

**答案怎么核才算数**：对着论文 Table S5 的**版面截图**（`shot_pdf.py --pages 54 55`）逐条核数字，不要对着抽取文本——这张表在 PDF 里存的是小数（0.4642），文本里搜「46.42」搜不到，会误判成编造。

| 答案里的数 | 截图结果 |
|---|---|
| GCS 缺失率 0.46% 对 27.57% | ✓ |
| 白蛋白 74.03% 对 57.92% | ✓ |
| PaCO2 46.42% 对 69.01% | ✓ |
| Elixhauser 在 eICU 100% 缺失 | ✓ |
| PaO2 同为 46.42% 对 69.01% | ✗ 实际 46.41% 对 68.70% |
| SpO2「均值」0.21% 对 4.01% | ✗ 这是 spo2_min 的**缺失率**，均值是 91.98/86.64 |

**那两处错的源头不是 LLM 综合，是入库精读句本身写错了**（精读者把 PaO2 与 PaCO2 的数字写混、把「缺失率」写成「均值」）。问答页只是忠实转述了它。所以问答回查还有一个副作用：**把精读库里的错句翻出来**——核到错了要改精读 bundle 源头（再 `regen --month <月> --no-topics`），不要只改问答页。

**这一类（实证数字、描述性对比）问答页综合基本可信，但仍要抽查**：数字类错误多半在上游精读句，而不是综合阶段。对照上面「反面示例」：定理/保证/界类论断的错是综合阶段把方向弄反，更危险。

## 汇报
