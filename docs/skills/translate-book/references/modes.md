# 模式选择与本书规则

当前 ID 以 `config/modes.json` 为准：

| ID | 选择依据 | 本书需要补充的约束 |
|---|---|---|
| 1 大陆哲学 | 哲学原典、严密概念论证 | 分清流派术语与普通词义，保留否定和推论范围 |
| 2 传记与历史 | 人物生平、历史非虚构、工人史 | 人名、职位、亲缘、年代、制度一致；不能把手工业者都改成工厂工人 |
| 3 批判理论 | 齐泽克、意识形态和文化批评 | 保留反讽与引述距离，不自动补理论家、出处或更强政治定性 |
| 4 AI 与数据科学 | 技术书、研究方法 | 公式、代码、数值、指标、缩写保真 |
| 5 小说与虚构 | 小说、书信体、心理叙述 | 人物声音、收信人与回忆层次一致；自然现代汉语，不补动作和心理 |
| 6 尼采专门模式 | 尼采原作且需要其节奏 | 不把所有隐喻都改成解释，不强化原文未有的断言 |

7 是摘要，不是全译；8 会显化逻辑，不能未经用户要求当作普通翻译。

项目某些通用 persona 示例有扩写倾向：例如把普通“问题”变成“内在矛盾”、给原文未提名的理论补归属，或把弱情绪改成强情绪。外层本书规则应明确：**忠实性优先于示例，不增加原文未有的主体、动作、论据、心理、出处或情绪强度**。脚本会为小说替换相关示例、为批判理论去掉两段已知会扩写的通用规则，同时保留共享模式文件。

术语不能只追求字面一致：同一普通词在不同语境可不同译；不同人物同姓不代表同一人；合作社和普通结社、神学恩宠和日常优美、拉康实在界和普通现实应逐处辨义。译注只解决必要的文化背景、专门概念或双关，不评价作者，不替作者纠正政治判断，不剧透小说。
