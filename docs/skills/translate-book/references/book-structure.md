# 复杂书籍结构：默认处理约定

这些规则用于源书有对应结构时。所有改动以核实的源文为依据，不靠删内容获得整齐版面。

## 先核实源提取

PDF 的 `page_index` 可能是合并片段的末页，不是片段首页。逐页把有实质文字的源页映射到缓存片段，用多个分布式源文窗口核验；不能只比较页数、段数或页索引。跨页句、脚注序列、双栏和横表单独查。只清除已核实的重复页眉、水印与断词并记录原缓存和理由；乱码未解决前不主译。文档结束、检查点完成和“无失败标记”都不能证明提取完整。

## 源译内容回查与补漏

分别核验源提取、译文内容和成品装载：源段全部命中只说明提取覆盖，译文通过长度检查只说明没有命中该候选，PDF/EPUB文字窗口通过只说明当前阅读层已装入成品。三者不能相互代替，也不能据此宣称全文逐句完整。

源 EPUB 的独立叶子块、标题序列、提纲行、诗行及脚注提供回查线索；图片内短字形、数学符号或引号可能把同一自然段打断，应回到 XHTML 核实。源 PDF 查跨页句、双栏、脚注续号和末页。除长段截断外，特别查长度阈值容易漏掉的短标题、整段提纲、编号后空缺及相邻段错位。

发现疑似漏译时先读源正文和当前已审译文，并查相邻段，排除内容移到下一段、合并在上一段或已有独立注释的情况。区分“文字已译而标题漏失”“标题编号错误”“正文或提纲完全漏译”。前两类精确恢复标题与编号，后一类补回实际内容；不能只补一个编号便标成完整。源本来是零散提纲时保留提纲形式，不扩写成连贯故事。

补回短标题或少量提纲可由实际审校模型直接处理，记录实际模型、源文件/段号与字符范围、对应中文句界和理由；需要重译较长正文时回到主译断点。含混地名、数量或省略句不强补关系，必要时保留不确定说明。补译后重新核对段尾、注号与前后衔接，并检查双格式中实际出现的位置。

旧译复用须证明源内容对应，不能按段号相同或少量译文窗口相似就批量导入。若旧 Markdown 含原文引用、重复标题或排版符号，先分离真正的中文层，再验证同源译文的完整对应；已完成的新译不因发现可复用旧译而无故回退。

## 跨章节拆分和阅读顺序

章题可能位于片段中间，原段同时含上一章结尾与下一章开头。保留主译和审校的原段号，只在阅读层拆分，不将上一章末尾带到新章标题下。核实章题是真实边界，区分分部标题、正文小节、分页续段与纯目录。

缓存的 `chapter_title` 可能从早先章节继承，`is_new_chapter` 也可能只在分页分组处出现。以源正文的独立标题及上下文为准，用目录辅助核对，不能直接采用旧旗标。标题在正文和旧目录双重命中时，用源文件、正文顺序和相邻标题去歧义，记录实际源段与字符范围；不能随意选一个命中或按字符比例猜插入位置。

若译文漏了标题，在源标题之后的实际句子与中文唯一对应句界恢复；若编号重叠或错置，要连同相邻标题和标题间正文一起核对。只有原编辑序号的片段保留序号，不编造题名。需清除旧章首旗标时，用 `chapter_metadata_updates` 更新阅读层元数据，不能据此移动或删去正文。

`reviews/render_policy.json` 示例：

```json
{
  "in_segment_headings": [{
    "segment_id": 46,
    "translation_sha256": "拆分前阅读层文字的SHA256",
    "prefix_is_continuation": true,
    "headings": [{"text":"第2章\n实际独立标题", "title":"第2章 实际独立标题", "toc_level":2}]
  }],
  "reading_text_edits": [{
    "segment_id": 2,
    "translation_sha256": "最终校正译文的SHA256",
    "edits": [{"start":0,"end":2,"expected":"目录","replacement":"","reason":"已核实旧导航，由新版目录代替"}]
  }]
}
```

`text` 必须唯一命中独立标题行或完整多行标题块；不得用宽泛匹配替代正文。字符下标按 Python 字符计数。文字清理先执行，章题拆分后执行：同段兼有二者时，拆分计划哈希绑定清理后的文字，清理计划哈希绑定最终审校译文。两者都不可绑定旧主译。重译或改变文字后重算并复核。

同段的人名统一、补译、标题修复等精确编辑须合为一份、使用同一基准译文坐标，检查范围互不重叠；不能串行套用不同版本的旧坐标。先合并语义修正，再应用已授权的删节隔离，再更新保留段章目元数据、应用阅读层文字编辑、拆分独立标题，最后生成两种格式。删节段不参与旧文字编辑或章题匹配。书前新说明及拆分产生的临时号动态分配，不在计划中猜测固定新号。

审核报告分别记录实际检查的缓存译文与语义修正后译文哈希；阅读层编辑和拆分计划再绑定各自版本。发现报告实际只审了缓存时，补查被修正内容并保留来源差异，不能仅重绑哈希冒充已审核。

拆分产生临时新段号和 `source_segment_id`；语义纠正仍写原段，不对临时号提交主译修正。`reading_order` 必须包含全部原段号，`reading_view_order` 必须包含全部阅读层段号，各恰好一次；拆分计划变化后临时号可能改变，重新生成排序。脚注、附录和作者介绍的顺序可整理，但不能丢任何片段。带正文的混合目录段只清理导航范围，不能整段省略。只在纯导航片段使用 `source_navigation`。

## 索引：重建定位，再排新版页码

先分清原索引的完整范围，尾随丛书广告或作者介绍不属于索引，必须另保留。

- EPUB：恢复父词目、子词目、see/see also 及原定位锚点。定位到实际源段，重建中文词目；不能只提取叶子节点。
- PDF：按实际双栏坐标和悬挂缩进恢复词目与续行；普通抽取会把左右栏、独立人名或续页粘连。检查列首、列尾、跨页和父子词目，不把分号一律当新主项。
- 数字先判语义：年份、日期、题名中的数字、注号与页码不同。“1968年5月”“9·11”不能拆成定位页。压缩页码范围如43–4先恢复43–44，明确记录采用首尾定位的精度。
- 用源页实际文字的多个分布窗口定位正文片段；记录印刷页码与物理页偏移，核查前言罗马页码及偏移变动，零未匹配才可声称完整定位。不要从译文词频猜目标。
- 词目保留稳定编号，DeepSeek 主译后核对编号集合恰好完整且无重复；复核同形异义、OCR损坏、人名和日期。正文已有的稳定中文人名保持一致，陌生专名可以保留短外文，不猜全名。

审计映射可保存为 `reviews/index_pdf_source_map.json`，每项至少含 `entry_id`、原词目、层级、源页、原定位及译文目标。索引标签单独审查用 `reviews/index_labels_review.json`；**不要用 `*_corrections.json` 后缀**，该后缀只供段级完整译文修正解析。

最终文件契约见 [review-format.md](review-format.md#索引与链接有该结构才处理) 的 `reviews/index.json`。PDF 页码由实际排版结果迭代取得，EPUB 链接指向真实 XHTML 文件及锚点；标明定位至译文片段起始处。保留原词目顺序与父子层级，核对词目总数、定位覆盖及所有链接。不要把旧版页码渲染成新页码。

不能只检查源链接存在：原电子书可能把“§113”错链成“第113页”，须核对定位符的语义并跳到真实节标题。索引的 `(Cont.)` 可能是跨栏续项，合并前查看原页，不能当成独立概念。若源书根本没有完整页码锚点，不用少数章首锚点插值或猜印刷页偏移；可以保留完整词目和明确标作“原书”的旧页码，`targets` 留空，在 `note_for_reader` 解释限制。该说明进入 PDF、EPUB、Markdown，索引章单独进入本版目录。

源注释或书目存在无法可靠恢复的 OCR 残损时，保留明确的不确定标记，前置中文译制说明，报告实际限制；不要凭语言流畅度伪造人名、题名或页码。

## 图片、矢量图与横表

默认清点源书封面、插画、图表和地图，有则保留；无须用户逐次提出。先区分整页扫描底图和独立视觉内容。不能把外文整页扫描图当插图嵌入单语正文。

PDF 的图片对象枚举会漏掉矢量图：同时检查原图表目录、图题、矢量绘制及代表页，逐项建立图号—物理页—正文片段清单。按真实图题/正文窗口定位插图，不简单把合并片段末页当图页。裁出独立图表，去掉周围正文和页眉；保留宽高比、图例、坐标轴和可读字号，配中文图注。必要短外文图内标签可以保留，不能借此放回外文正文。

横表或复杂表被抽取打散时，回到原页逐格恢复。可拆成多个中文分面图，保留行列对应、权重、单位、空白格和表注；不把不确定的空格填成零。记录源页及重建依据，并独立核对单元格。原图清楚且无需重绘时直接保留。

资产与SHA256按 [rendering.md](rendering.md#扫描件与原书图片) 保存到 `visual_assets.json`。PDF、EPUB使用同一清单，验收图片实际入包、位置、完整性、清晰度与图文跨页；审查图表目录中每一项是否有正文对应，而不是只检查提取到的栅格图片。

已保留真实封面或标识后，清除相应的纯图片文字占位，不能留下“[插图：封面]”空页。检查最终 PDF 实际含图的页面；片段首所在页不一定是插图页，分页可能把图移到下一页。

## 交付前的实际核验

`validate_delivery.py JOB` 检查最终 EPUB 的 ZIP/XHTML、全部本地链接与段落锚点、资产字节哈希；逐段抽取分布的汉字窗口检查双格式覆盖，并检查 PDF 文字边界和失败标记。PDF 窗口容许文字抽取带来的局部差异，但任何候选须复核，不能用放宽阈值掩盖漏载。短段、数字和公式仍需针对性检查；机器通过不能证明全文语义或版式无误。

用当前环境 Poppler 生成最新封面、目录、各类正文、章首、脚注、索引、末页及代表图表的预览并实际查看；诗歌另查诗行和呼告，学术书另查注释和长章题。记录视觉检查页号、最终文件哈希、审核者与范围。最终结论区分“抽检校正”与“全文精校”。验收后再按 skill 默认规则复制 PDF/EPUB 到 `~/Downloads/翻译成果/书籍/`，核对副本哈希并保留项目原件。
