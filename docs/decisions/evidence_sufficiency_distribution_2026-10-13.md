# 证据充分性：按分布动态决定的判据（WO-4b，2026-10-13）

接续 `evidence_sufficiency_calibration_2026-10-13.md`（WO-4，固定 sim 下限 + 独立来源数 ≥k）。用户要求「拒答阈值不要固定，看分布动态决定」，本档案找出并量化比较了几种分布判据。**不改 `thresholds.py`**（WO-5 的事），推荐常量见第 6 节。

## 0. 结论（先看这个）

1. **分布判据能做，但没有显著胜出。** 最好的动态判据（背景 z* + 下限 + 来源数，下称「候选 B」）在样本内漏拒 1/13（固定阈值 3/13），代价是 4 个正例的来源数恰好等于 m（余量 0）；稳一档的设置（余量 1）漏拒 3/13，与固定阈值持平。
2. **留一（leave-one-out，33 个样本逐个拿掉）两者持平：动态漏拒 3/13，固定也是 3/13**，误拒都是 0。也就是说样本内那一点优势没有通过留一检验。
3. **离题召回 6–12 篇来源的三个难例（机器人抓取、影像分割数据增强、糖尿病视网膜病变筛查）仍然分不开。** 单特征 AUC 显示：归一化后的 z 分数（z3 0.94）并不比原始分数（raw3 0.95）更能区分正反例；曲线形状类特征（top1 与第 k 名落差）AUC 只有 0.65–0.70，基本无效；离题零分布与固定阈值等价（本质还是看原始分数）。「相邻但画像外」的问题在库里有真实的方法学近邻，不是阈值没调好，而是语义相似度本身就不区分它们。
4. 动态判据的**真实价值**在别处：背景高的泛化问题（如机器人抓取，背景均值 0.427）自动抬高门槛，背景低的冷门问题（Rubin 1976、影子变量，背景均值 0.35）自动降到下限，这比一刀切 0.60 更合理；并且不依赖召回截断参数（top-80、relative_alpha、per_paper_cap）。但这个价值在当前 33 个样本上量化不出来。

次优建议见第 7 节。

## 3. 各候选判据的分离结果

### 3.1 候选 A：固定阈值（对照基线，全库口径）

选择规则结果 0.60 / k=2：误拒 0/20，漏拒 3/13（机器人抓取、影像分割数据增强、糖尿病视网膜病变），余量 0。留一：误拒 0，漏拒 3/13。

### 3.2 候选 B：逐问题背景分布（本档案的主候选）

判据：`T = max(floor, mean + z*·std)`，`z* = Φ⁻¹(1 − e/N)`；独立来源数（最高分 ≥ T 的 keeper）< m 则拒答。三个参数 floor（绝对下限）、e（期望靠偶然越界的背景点数，替代手调的 z 阈值）、m（来源数）。z\* 本身不手调，随 N（mask 内 chunk 数）自动变化，N=37142 时 e=1 对应 z\*≈4.04，N=26489（adversarial-evidence 带 roles 过滤）时 ≈3.96。

网格摘要（正例 = pos + niche = 20；漏拒分母 13；完整网格见 `--json-out` 的 `dynamic_rows`）：

- 选择规则（误拒 = 0 → 漏拒最少 → 余量大 → floor 小 → e 大 → m 小）选出 **floor 0.58 / e=1 / m=3**：漏拒 1/13（只剩糖尿病视网膜病变），其中平凡反例 0 个被漏。
- **悬崖**：沿任何一个参数方向多走一小步就出现误拒（m=4：5 个正例被拒；e=0.5（m=3）：2 个正例被拒；floor 0.60 + m=3：1 个被拒）。可用平台宽度约为 z\* 的 0.25–0.5 个单位，不宽。
- **floor 为何不能省**：纯 z（floor=0）会让平凡反例通过（中世纪农业史 z1=5.4，高于不少正例）。floor 0.58 是绝对相似度常数，**不是**随分布动态的部分；它在冷门问题（Rubin 1976、影子变量、自遮蔽、MNAR 诊断页）上是真正起作用的那个阈值（表中 T=0.580 的行），动态部分主要作用在背景高的问题上。如实说：这个判据 = 固定下限 + 逐问题抬高门槛，不是完全无固定常数。
- 留一：误拒 0/33，漏拒 3/33（NICU、影像分割、糖尿病视网膜病变）。**与固定阈值的留一结果（机器人抓取、影像分割、糖尿病视网膜病变）同样是 3**，样本内 1/13 对 3/13 的优势不能外推。

### 3.5 候选 4：组合判据

候选 B 本身就是组合判据（背景显著性 + 来源数 + 绝对下限）。「至少 m 个来源超出背景 p99.9」没有单独做：quantile 阈值下超阈 chunk 数恒约为 N 的固定比例（p99.9 恒有 ≈37 个 chunk 越界），与问题是否在库内无关，在探索阶段看到所有样本的 n≥p99.9 都在 12–37 之间，不可用，所以改用基于高斯尾概率的 z\*。

## 4. 平凡反例单列

三个平凡反例（中世纪农业史、小麦氮肥、新冠抗体）在 floor ≥ 0.55 的任何设置下都是 0 个来源，**无论哪个判据都拦住了**，所以不计入任何判据的加分。表中「漏拒 x/13」的分母含它们，报告里同时给出「非平凡 10」口径：候选 B 选定设置漏 1/10，固定 0.60/k=2 漏 3/10。

## 5. 运行时成本

- 向量库一次性加载 0.2–0.8 秒（读 SQLite + 45835×1024 float32 矩阵，约 190MB；ask_notes / build_topics 本来就加载）。
- 每个问题：构 mask 约 5ms（Python 循环 45835 条记录；可缓存）+ 全库相似度扫描约 13ms（一次矩阵乘 + 取 max，含所有 query 向量）+ 来源去重 O(N) 约毫秒级。**总计 < 25ms/问题，不含 embedding 请求。** 与召回本来就要做的 `store.search` 同量级，实际可以复用同一次矩阵乘（召回内部 `mat @ query_vec`，本函数是多 query 取 max 的版本）。
- 内存：N=3.7 万个分数的数组，300KB，可忽略。

## 7. 取舍与次优建议

- **如果用户坚持动态阈值**：采用 floor 0.58 / e=1 / m=3，漏拒 1/13，但接受「4 个现有正例恰好卡线」。这些正例是 adversarial-evidence 概念页、complete-case 与共形预测第二个归档页、Rubin 1976（代拟）；只要出现一个更冷的真实问题，这条线就会误拒。配合 Q8「宁可回避不足」，更稳的是 **m=2**，此时和固定 0.60/k=2 的漏拒数相同，但阈值随问题漂移、不依赖召回截断，可解释性更好。
- **如果优先保证不误拒**：固定 0.55 / k=3（WO-4 设计初值）几乎不拒答（漏拒 10/13），拒答闸形同虚设；这类问题（相邻但画像外）真正靠得住的拦截不是阈值而是覆盖范围说明（6.4 节，WO-5 主体），即让读者看到「本页证据来自 x 篇、库是方法学画像库」，由人判断。
- **概念页**：9 个概念页在候选 B 下 3–38 个来源（最低 adversarial-evidence 3），比 WO-4 召回口径下的 45+ 余量小得多：概念页背景高（均值 0.46–0.48），动态阈值被抬到 0.63–0.69，高于固定 0.60。**概念页不建议切到动态判据**，沿用 WO-4 档案的 0.55 / k=3（余量 41）。
- **要真正分开难例需要不同类型的信息**，不是更聪明的相似度阈值：例如（a）画像词表命中（问题是否含库画像内的实体）；（b）召回 top 文献的筛选裁决历史（它们是以什么理由入库的）；（c）问题与库的「领域级」相似度（paper 级向量的聚类归属）。这些都超出本工单范围，列为后续。

## 8. 需要用户确认的点

1. 代拟的 5 道冷门正例是否替换为真实问题（影响本档案所有数字，尤其是余量 0 的那 4 个）。
2. 取舍：激进 m=3（漏拒 1/13，余量 0）还是稳 m=2（漏拒 3/13，余量 1）。
3. 是否接受「分布判据没有显著优于固定阈值」的结论，由 WO-5 自行选择接固定还是动态；两套纯函数都在 `coverage.py`。

## 9. 换 embedding 模型后的重标定

1. 重建向量库（路线图下一批的 embedding 换型）后，对新库拷快照，复跑 `python scripts/calibrate_evidence_sufficiency.py --mode distribution --notes-dir <新快照>`。
2. 不同模型的余弦分布整体不同（均值、方差都会变），所以 **floor 必须重标**，z\* 和 e 不需要：背景统计是逐问题现算的。重标顺序：先看第 2 节特征表里平凡反例的 top1，确定 floor 应高于它们，再看 `dynamic_rows` 找误拒=0 的最小 floor。
3. 重标前先检查三类信号：（i）背景 mean/std 是否仍落在 0.2–0.5 / 0.03–0.06 附近（异常说明归一化或维度有变）；（ii）平凡反例的来源数是否仍为 0；（iii）留一漏拒数是否仍不劣于固定阈值。
4. 样本应换成用户确认的真实冷门正例（第 8 节第 1 点）和 ≥3 条真实被打回的越界问题；24 条探针需要剔除库里有真实近邻的（脓毒症、eGFR 等）。

## 10. 限制

- 样本小：正例 20（含 5 条代拟）、反例 13（含 3 条平凡）；网格结论是「在这批样本上零误拒」，不是统计保证。网格 5 floor × 5 e × 4 m = 100 格从 33 个样本里选，有选择偏差，留一结果是更诚实的数字。
- 独立来源只做 keeper 去重，不合并作者组（Q6）。
- 全库口径不含 `relative_alpha`；概念页若要沿用 alpha 需要在召回后另行计数。
- z\* 假设背景近似高斯；实际尾部偏重，所以 e=1 对应的「期望越界 1 个」是名义值，不是真实误报率，不要拿它做显著性解释。
