## 铁律

1. **只能用上面列出的证据**。不许写入证据里没有的论文、数字、结论、方法名。你自己知道的其他文献一律不许出现——这一页的价值全在于"可追溯到我库里的哪一句"。
2. **引用只写编号**，形如 `["E3", "E7"]`。**绝对不许写 citekey、作者名年份、文献标题**当引用标记——引用由程序按编号回译，你若在正文里写出任何 citekey，程序会把它整段剥离，不会被保留成引用，并计入违规计数。
3. 每一条 claim **必须**至少有一个证据编号。凑不出证据的话就不要写这条。
4. **分歧优先于和谐**。证据之间若有冲突（同一问题不同结论、条件不同导致结论翻转），必须写进 `disputes`，并把冲突双方的编号分别列在 `evidence_a` / `evidence_b`。不要为了让页面读起来顺畅而抹平冲突——标记冲突正是这一页存在的理由。
5. 证据不足以回答核心问题的部分，写进 `gaps`（写清"缺什么类型的证据"，而不是泛泛说"研究尚不充分"）。gaps 不需要编号。
6. 论断要**具体**：带上条件、数据集、效应量。"多项研究表明该方法有效"是废话；"在 MIMIC-IV 上掩码嵌入使 AUROC 提升 0.02，但在跨库外验时收益消失"才是论断。
7. 有上一版本时，把它当作草稿修订：保留仍被证据支持的论断，删掉已被新证据推翻的，补上新证据带来的。不要因为某条旧论断这次没检索到证据就删——只在**有反向证据**时才删或改标为争议。
8. **转述并列数字必须完整**。证据里若出现同一组比较的多个数字（如几种方法/几个子组各自的效应量），转述时要么全部列出，要么明确说"其中最弱 X、最强 Y"——不许只挑对论断有利的几个、把最弱的那个静默丢掉。给数值范围时，两端必须是这组数字里真实的最小值和最大值，不能只用部分子集的极值冒充整体范围。

   ⚠️ 这条**同样适用于 `disputes` 里的 `position_a` / `position_b`**。实测踩过：同一页里
   正文小节老实列出了「66.0、4.4、70.2、64.4」四个值，分歧区却把同一组数字写成「64.4–70.2」，
   真实范围其实是 4.4–70.2（差 16 倍）。分歧区尤其危险——它是最容易被直接摘去写作的地方，
   而丢掉最不利的那个数字恰好让你支持的那一方显得比实际更强。同一组数字在同一页的
   不同位置必须口径一致。
9. **不得删除原句的限定语**。证据原句里的"可""可能""启发""值得借鉴"这类推测性措辞是作者留下的不确定性标记，转述时必须保留同等强度的推测语气，不能把"可能启发 X"改写成"证明了 X"或"X 已被证实"。
10. **分歧两侧必须来自不同文献**。同一篇论文的两处批注（比如同时有「对我研究的联想」与「局限与可质疑点」两条）不构成分歧，只是同一现象的两个角度——不要为了凑够 `disputes` 硬把它们拆成一方一方。
11. **域外证据必须标注领域**。证据若来自非临床/非 EHR 领域（图像识别、文本、通用机器学习基准数据集等），写进论断时必须显式标注该证据的领域来源，并注明"尚未在 EHR/临床数据上验证"——不得把跨域实证平铺直叙成对本页临床问题的支持。

## 输出格式

只输出一个合法 JSON 对象，不要解释文字，不要 Markdown 代码围栏。

⚠️ **JSON 字符串值内部一律不得出现半角双引号 `"`**。要加引号时用中文引号「」或『』。
（实测踩过：写成 `专门"诊断MNAR"的方法` 会当场破坏 JSON，整页作废。）
换行请写 `\n` 转义，不要直接换行。

```
{
  "summary": "150 字以内的总述：这一页回答了什么，当前证据的总体图景是什么",
  "sections": [
    {
      "heading": "小节标题（自拟，如「主流方法与前提假设」「实证效果」）",
      "claims": [
        {"text": "一条具体论断", "evidence": ["E3", "E7"]}
      ]
    }
  ],
  "disputes": [
    {
      "issue": "争议点一句话",
      "position_a": "一方主张",
      "evidence_a": ["E2"],
      "position_b": "另一方主张",
      "evidence_b": ["E9"],
      "note": "可选：为什么会分歧（数据集/口径/条件差异）"
    }
  ],
  "gaps": ["缺口一：需要什么类型的证据才能回答", "缺口二：……"]
}
```

`disputes` 与 `gaps` 可以为空数组，但 `sections` 至少要有一节。
